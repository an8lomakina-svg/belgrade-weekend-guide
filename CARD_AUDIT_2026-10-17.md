# Аудит соответствия карточек шаблону — 17.10.2026

Основа: `index.html` (GitHub blob `d8c3bcaba5d764437afb174d31ebd70c82a853f2`) и `CARD_TEMPLATE.md`.

## Результат автоматической структурной проверки
- Карточек в актуальном наборе: **151** (после исключения завершившегося события на 17.10.2026).
- Структура массива: **136** карточек по 8 полей, **6** по 9, **9** по 10. Это не означает 8–10 полей шаблона: большинство требований задаётся дополнительными объектами и рендерингом.
- Название, описание и адресное поле присутствуют во всех 151; адресное поле нередко содержит поисковую фразу вместо точного проверенного адреса.
- **49** карточек без индивидуального URL в базовом поле ссылки; некоторые могут иметь URL в дополнительных справочниках. Для остальных UI генерирует поиск официального сайта вместо прямой ссылки.
- Для **78** карточек найдено связанное значение расписания/часов в основных словарях; это не независимое подтверждение актуальности, а часть значений — отправление экскурсии или расписание посещения. Для остальных — общий текст-подсказка, ссылка на карту или режим общедоступной прогулки.
- Для **34** карточек найдено явное значение цены из основных словарей **или** категория бесплатной публичной прогулки/парка. В этих 34 есть 18 карточек прогулок/парков; это не означает подтверждённые билеты или меню остальных. Дополнительные поля отдельных карточек содержат текстовые диапазоны, поэтому это **нижняя граница структурированного покрытия**, а не точное число карточек без цены.
- Реальные фото сопоставлены по имени для **22** карточек из словарей `photos` и `commonsPhotos`. Для остальных генерируется SVG-изображение `knitArt(x)`; индивидуальная художественная уникальность и права на все фотографии этим аудитом не удостоверены.
- Прямые Instagram-ссылки есть в `instagramLinks` у **6** карточек. Для прочих выводится ссылка на поиск Instagram.
- Словарь индивидуальных Telegram-профилей в рендерере отсутствует.
- Единая дата фактической проверки для каждой отдельной карточки отсутствует. Текст аудита в UI иногда показывает фиксированную дату 15.10.2026 для целой группы; это не эквивалент индивидуального фактчекинга.
- Повторяющихся **точных названий** и ссылок с неправильным форматом HTTP(S) в структурном анализе не обнаружено. Это не доказывает работоспособность URL, правильность адресов или отсутствие смысловых дублей.

3. Верифицировать часы и цены у источника для каждого заведения; при неизвестном значении показывать «Не подтверждено».
4. Проверить отдельно реальные фото и лицензии, а также SVG-иллюстрации; по возможности сохранить атрибуцию.
5. Уточнить классификацию и проверить отображение каждого фильтра на реальных данных.
6. Для событий регулярно сверять даты, билеты и актуальность афиши.

**Ограничение:** это проверка соответствия структуры всего каталога шаблону, а не подтверждение каждого факта посредством 151 внешнего первоисточника. Не маркировать данный отчёт «полная внешняя проверка».
