⚡ Перед выходом: реальные фотографии показаны только для мест с найденными публичными снимками и указанием источника. Для остальных есть переход к фотографиям на карте — не подменяем место чужими фото. Перед визитом проверь часы работы, возрастные ограничения, бронь и цены. Оценки бюджета ориентировочные; некоторые места — для напитков или десерта, а не полноценного ужина. Некоторые позиции из первоначальной подборки были идеями без подтверждённого названия.
Создано как интерактивный путеводитель. Поиск и фильтры работают без регистрации. Сохранённые места остаются в этом браузере. Фотографии загружаются с сайтов источников при подключении к интернету. Ссылки Google Maps открывают поиск по названию, а не всегда подтверждённую карточку места.
