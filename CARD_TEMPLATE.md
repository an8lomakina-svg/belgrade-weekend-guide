# Единый шаблон карточки — гид Белграда

Применять к каждой НОВОЙ карточке и при обновлении существующих. География: только Белград. Не удалять реальные сведения ради соблюдения шаблона.

## Структура
1. Фото места с разрешёнными правами и указанием источника/автора, либо индивидуальная вязаная иллюстрация по конкретному месту. Не подменять фото случайными фотографиями.
2. Название заведения / события.
3. Категория, кухня/тип и район Белграда.
4. Краткое точное описание в 2–3 предложениях: что уникально и почему посетить.
5. Точный адрес и прямая ссылка на Google Maps места (если подтверждено); иначе адрес с явным статусом проверки.
6. Дни недели и время работы, включая исключения — с первоисточником. Для событий: дата, начало, место и ссылка на билеты; для экскурсий: расписание/порядок бронирования.
7. Стоимость: вход / диапазон стоимости / конкретные примеры из меню, с валютой RSD и источником; если динамическая — «зависит от даты/сеанса/заказа».
8. Особенности и тематические метки для фильтров, подтверждённые источником: кухни, завтраки, терраса, с детьми, с питомцем, доступность, тип мероприятия и т.п.
9. Ссылки: Google Maps, официальный сайт, официальный Instagram, официальный Telegram, бронь/билеты — только реально найденные и проверенные профили. Отсутствующие не выдумывать и не выдавать поиск за официальный профиль.
10. Дата фактической проверки каждого изменённого факта и источник. Не маркировать карточку «проверено сегодня», если проверки не было.
11. «Нужно знать»: обязательная бронь, наличные, возрастные ограничения, доступность с коляской и другие особенности, только если подтверждены.

## Достоверность и наполнение
- Нельзя придумывать часы, цены, адреса, Instagram, Telegram, меню, ссылки, мероприятия и права на фотографии.
- Если достоверных данных нет, показывать «Не подтверждено» либо «Уточняйте на сайте заведения/организатора». Данные без источника не считать проверенными.
- Для карточек с меняющейся афишей указывать проверенный репертуар/расписание; удалять завершённые события из выдачи.
- До добавления проверять дубликаты, затем валидность ссылок, синтаксис JavaScript и фильтры.
- Не добавлять карточку с бессмысленной/неверной меткой только для наполнения фильтров.
- Для новых карточек стремиться к полному набору подтверждённых полей, но честно показывать пробелы.

## Визуальный порядок
Изображение → категория и район + избранное → название → описание → адрес → часы → стоимость → особенности/«Нужно знать» → ссылки → статус и дата проверки.

## Источники
По приоритету: официальный сайт и соцсети заведения / организатора, официальная афиша, турорганизации и музеи; затем надёжные специализированные каталоги; Google Maps и публичные Telegram-подборки — как вспомогательные источники, с перепроверкой по первоисточнику.
