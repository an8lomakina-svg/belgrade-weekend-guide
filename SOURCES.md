# Реестр источников — гид Белграда

Это канонический реестр для обновлений. Публичный каталог на сайте — его витрина, но не замена этому файлу.

## Правила использования

- Роль «первичный или организатор» приоритетна для часов, цен, билетов, статуса работы и условий посещения.
- Каталоги, карты, агрегаторы и сообщества используются для поиска кандидатов; они не подтверждают факты сами по себе.
- У каждой новой записи обязательно указывать тему, роль, назначение и дату фактической проверки URL.
- «Дата проверки URL» означает проверку доступности и релевантности самого источника, а не автоматическую проверку всех карточек, найденных через него.
- Перед добавлением новой записи проверять дубли по домену, названию и назначению. Разные разделы одного домена допустимы, когда у них разная задача.
- При наличии времени в тематическом запуске расширять реестр новыми независимыми первоисточниками и повторно проверять существующие URL. Приоритет повторной проверки: ближайшие события → официальные площадки → билетные сервисы → каталоги и сообщества.
- При недоступности URL не удалять источник автоматически: зафиксировать дату, статус и причину, затем искать официальный заменяющий источник.
